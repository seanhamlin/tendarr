Scheduled release checks

Works through the candidate lists in the background, running an interactive search for each item and recording whether a better release is available. It never grabs anything: results appear under Upgrade available for you to act on. One budget covers Radarr and Sonarr together, because they usually search the same indexers.

Scheduled upgrades

Asks Radarr/Sonarr to search for and grab an upgrade, one item at a time, choosing the item whose acceptable release frees the most space. Only items a release check found an upgrade for are considered, so this works best alongside scheduled release checks, and uses the same codec and size filters. Results older than the re-check window are not trusted.
